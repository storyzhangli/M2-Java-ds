## 本轮最小实施清单

1. 在既有 `PromptScenes` 中扩展设备客服、设备技术工程师两个稳定场景，不新增含义重复的枚举。
2. 新增两个版本化种子 Prompt，变量、正文、更新时间均由现有模板模型和数据库管理。
3. 新增 `prompt_template_version` 归档表及仓储，保存每次更新前的不可变快照；既有模板启动时幂等回填。
4. 新增设备故障事实提取、澄清策略和只读工单候选 DTO；不连接正式工单表、不创建派单副作用。
5. 新增设备对话入口，复用现有模板、MySQL 会话、上下文窗口、知识检索与模型服务。
6. 默认 Mock 模式走确定性规则和本地结果；新增测试不要求真实 Key，不访问 DeepSeek 外网。
7. 修复旧项目日志路径导致的启动阻断，并把日志默认目录指向当前 D18 约定的 logs 目录。
8. 运行定向测试、模块测试、全量回归和敏感信息扫描，生成两份正式文档及证据索引。
