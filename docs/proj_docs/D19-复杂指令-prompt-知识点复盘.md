- 模型请求调用工具。

必须明确：模型生成工具调用请求，不等于工具已经执行；JSON 输出与 Tool Calling 也不是同一种功能。

#### 6.4 JSON 输出与工具调用的对比

必须对比：

| 比较维度 | JSON 结构化输出 | Tool Calling |
|---|---|---|
| 核心目标 | 返回结构化数据 | 请求应用执行指定工具 |
| 模型响应 | JSON 或可映射的结构化内容 | 工具名称与参数 |
| 实际执行者 | 通常由业务逻辑处理数据 | 应用程序负责执行已授权工具 |
| 关键校验 | JSON、类型、字段及业务规则 | 工具名称、参数、权限及执行结果 |
| 主要风险 | 格式错误、信息错误、无依据内容 | 参数错误、越权、副作用、重复执行 |
