原现状：

- `spring.ai.deepseek.*` 直接读取 `DEEPSEEK_*` 环境变量。
- `app.ai.mode` 单独读取 `AI_MODE`。
- Controller 直接读取供应商模型名配置。
- Mock 模式下仍依赖无效占位 Key 让供应商自动配置装配模型。

Spring AI 1.1.8 的 DeepSeek 自动配置对 Key 执行 `Assert.hasText`，空 Key 时无法创建 Bean。

## 4. 设计方案

### 4.1 单一应用配置源

`app.ai.*` 成为唯一应用级模型配置：

```yaml
app:
  ai:
    mode: ${AI_MODE:mock}
    model: ${AI_MODEL:deepseek-flash}
    base-url: ${AI_BASE_URL:https://api.deepseek.com}
    api-key: ${AI_API_KEY:}
    temperature: ${AI_TEMPERATURE:0.7}
    thinking:
      reasoner-model: ${AI_REASONER_MODEL:deepseek-reasoner}
```

### 4.2 模型 Bean

- 主配置禁用 `DeepSeekChatAutoConfiguration`。
- 新增 `DeepSeekChatModelConfiguration`。
- 仅 `app.ai.mode=deepseek` 且容器没有其他 `ChatModel` 时创建 `DeepSeekChatModel`。
- 该配置使用 `app.ai.*` 构造 `DeepSeekApi` 和 `DeepSeekChatOptions`。
- Mock 模式不创建供应商 ChatModel。

### 4.3 服务契约

`AiChatService` 保持为应用 Port：

- 参数和返回只包含项目内部 `ChatInvocation`、`AiChatResult`、`ChatReplyResponse`、`StreamChunk`、`Flux`。
- Controller、Orchestrator、DTO 不出现 DeepSeek 包类型。
- DeepSeek 专有类型只在：
  - `config/DeepSeekChatModelConfiguration.java`
  - `service/DeepSeekAiChatService.java`

### 4.4 兼容与复用

未改动：

| `app.ai.thinking.reasoner-model` | `AI_REASONER_MODEL` | `deepseek-reasoner` | 思考模型 |

### 5.1 优先级

Spring Boot 标准优先级：

1. 命令行参数。
2. 操作系统环境变量。
3. 外部 Profile 配置。
4. `application.yml`。
5. Java 默认值。

配置在启动时绑定，不支持运行时热切换。

### 5.2 校验

- mode 只允许 `mock`/`deepseek`。
- model/reasoner model 不能空白。
- Base URL 必须是带 host 的 http/https URI。
- Base URL 禁止 user-info，防止配置中夹带凭据。
- 温度 0–2。
- 真实模式空 Key：
  - 正常 Provider Bean 构造时启动失败，错误不回显 Key；
  - 如果测试注入 Mock ChatModel，Service 在调用前返回既有 5001。

## 8. 真实模式运行

先在 IDEA Run Configuration 或受控进程环境中注入：

```text
AI_MODE=deepseek
AI_MODEL=deepseek-flash
AI_BASE_URL=https://api.deepseek.com
AI_API_KEY=<由秘密管理器提供>
AI_REASONER_MODEL=deepseek-reasoner
AI_TEMPERATURE=0.7
```

IDEA 操作：

1. 打开 `Run | Edit Configurations`。
2. 选择 D22 Application。
3. 在 Environment variables 中添加上表变量。
4. `AI_API_KEY` 使用 IDEA 密码/外部秘密源，不直接写进项目文件。
5. 启动应用。

PowerShell 只设置非秘密或当前进程秘密：

```powershell
$env:AI_MODE = "deepseek"
$env:AI_MODEL = "deepseek-flash"
$env:AI_BASE_URL = "https://api.deepseek.com"
# AI_API_KEY 必须由当前进程的安全秘密注入机制提供，不在此写值。
```

`.env` 不会被 Spring Boot 自动读取，本项目没有 dotenv 加载器。
